# NixOS 系統配置文件結構完全指南

從入門到企業級架構的實戰教學

## 快速上手

```bash
# 進入 Nix 開發環境（需安裝 Nix + Flakes）
nix develop

# 本機即時預覽
make serve

# 建構 HTML
make build

# Markdown 格式檢查
make lint
```
