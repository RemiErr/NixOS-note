# 學習路線圖

本書設計為三個遞進階段，每個階段有明確的學習目標與對應章節。

---

## 整體學習路徑

```text
【初學者階段】
第一篇 → 第二篇 → Lab 1~3
理解思維模型，能讀懂並修改 configuration.nix
         ↓
【中階階段】
第三篇 → 第四篇 → 第五篇 → Lab 4~6
掌握系統實務，遷移至 Flakes，管理多主機
         ↓
【高階階段】
第六篇 → 第七篇 → 第八篇 → Lab 7
進階配置、部署自動化、企業級架構
```

---

## 初學者階段（第1–7章）

**目標：** 能獨立建置並維護單機 NixOS 系統

| 章節 | 主題 | 核心能力 |
|---|---|---|
| 第1章 | NixOS 的設計哲學 | 理解宣告式系統與 immutable 的意義 |
| 第2章 | Nix 語言基礎 | 能讀懂 attribute set、function、let/in |
| 第3章 | NixOS 配置系統概覽 | 理解 configuration.nix 的角色與評估流程 |
| 第4章 | configuration.nix 基本結構 | 能從頭建立完整的基礎配置 |
| 第5章 | imports 機制與模組化設計 | 能將配置拆分為多個檔案 |
| 第6章 | Option 系統與 mkOption | 能查閱 option 文件並正確使用 |
| 第7章 | NixOS Module System | 理解 module 評估機制 |

**完成後你能做到：**

- 安裝套件、啟用服務、建立使用者
- 將 configuration.nix 拆分為模組化結構
- 執行 `nixos-rebuild switch` 並理解發生了什麼

---

## 中階階段（第8–20章）

**目標：** 能管理多主機環境，使用 Flakes 建立可重現配置

| 篇 | 主題 | 核心能力 |
|---|---|---|
| 第三篇（8–12章） | 系統配置實務 | 硬體、網路、使用者、套件的完整管理 |
| 第四篇（13–16章） | 服務配置架構 | systemd、常見服務、桌面環境、開發環境 |
| 第五篇（17–20章） | Flakes 與現代架構 | 多主機管理、Home Manager、大型配置架構 |

**完成後你能做到：**

- 建立完整的桌面或伺服器 NixOS 環境
- 用 Flakes 管理多台機器的配置
- 整合 Home Manager 管理使用者環境
- 建立 `hosts/`、`modules/`、`profiles/` 的模組化架構

---

## 高階階段（第21–32章）

**目標：** 能設計並維護企業級 NixOS 基礎設施

| 篇 | 主題 | 核心能力 |
|---|---|---|
| 第六篇（21–25章） | 進階配置與最佳實踐 | Overlay、Secrets、自訂 Module、部署自動化 |
| 第七篇（26–28章） | 除錯與維護 | 排錯、升級策略、常見陷阱避免 |
| 第八篇（29–32章） | 企業與基礎設施場景 | 伺服器模式、雲端、GitOps、團隊協作 |

**完成後你能做到：**

- 使用 deploy-rs 或 colmena 遠端部署
- 用 sops-nix 或 agenix 管理機密
- 建立可供團隊共用的 reusable module
- 設計 GitOps 工作流程管理整個基礎設施

## 建議學習節奏

| 目標 | 建議時間 | 章節範圍 |
|---|---|---|
| 理解基礎，能操作 | 2–3 週 | 第1–7章 + Lab 1–2 |
| 建立完整工作環境 | 再 3–4 週 | 第8–20章 + Lab 3–6 |
| 進階架構能力 | 再 4–6 週 | 第21–32章 + Lab 7 |

時間僅供參考。每個人的背景不同，不必急於趕進度。

NixOS 的學習曲線在前三章最陡，一旦建立了思維模型，後面的內容會越來越順暢。
