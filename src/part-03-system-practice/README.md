# 第三篇：系統配置實務

前兩篇建立了理論基礎。

本篇進入實務：你會看到 NixOS 如何處理系統的每個面向——從硬體偵測到網路配置，從使用者管理到套件安裝。

每個主題都會從「NixOS 的方式」出發，對比傳統 Linux 的做法，讓你理解差異與優勢。

---

## 本篇章節

| 章節 | 主題 |
|---|---|
| 第8章 | 硬體配置文件 |
| 第9章 | Boot 與 Kernel 配置 |
| 第10章 | 網路配置 |
| 第11章 | 使用者與權限管理 |
| 第12章 | 套件與環境管理 |

---

## 本篇學習目標

完成本篇後，你將能夠：

1. 理解 `hardware-configuration.nix` 的自動生成機制
2. 配置 GRUB 或 systemd-boot 開機程式
3. 設定靜態 IP、WireGuard 和防火牆規則
4. 管理使用者、群組、SSH 金鑰與 sudo 規則
5. 安裝套件、設定 overlay、管理 unfree 套件

---

## 前置要求

- 完成第二篇（理解 imports 與 module system）
- 有完整可操作的 NixOS 環境
