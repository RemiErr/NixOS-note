# 前言

Linux 世界長期存在一個問題：

系統配置會隨著時間逐漸失控。

你可能曾經遇過：

- 不知道當初修改了哪些設定
- 套件版本互相衝突，裝了 A 就壞了 B
- 重灌系統後，環境怎樣都無法完全重現
- Server 與 Laptop 的配置漸漸走樣
- 更新後系統壞掉，不知道哪個地方動了
- 不敢升級 production 環境，因為上次踩了坑
- 不知道是哪個 shell script 悄悄改動了系統

這種現象有個名字：

**配置漂移（Configuration Drift）**

---

NixOS 的核心目標，就是從根本上解決這個問題。

它不是「另一個 Linux 發行版」而已。

它更像是：

- Infrastructure as Code，落實在作業系統層
- 可重現系統：相同配置，永遠得到相同結果
- 宣告式作業系統：你描述「應該是什麼」，而不是「做什麼」
- 版本化配置管理：每次變更都可追蹤、可回滾
- 原子化部署平台：切換要麼全部成功，要麼完全不動

---

## 本書的目標

本書不是一本指令手冊。

它是一本：

「如何設計可維護 NixOS 系統架構」的工程實戰書。

本書將從完全初學者的角度出發，逐步建立：

1. **NixOS 思維模型**：先理解為什麼，再學怎麼做
2. **Nix 語言基礎**：看懂並寫出配置的能力
3. **configuration.nix 架構**：掌握系統配置的核心
4. **模組化配置設計**：讓配置可維護、可重用
5. **Flakes 現代化配置**：工程化的依賴管理
6. **多主機管理**：用同一份 repository 管理多台機器
7. **企業級 NixOS 架構**：從 Homelab 到生產環境
8. **GitOps 與 CI/CD**：讓系統變更像軟體發布一樣可靠

---

## 本書適合的讀者

**適合你，如果你：**

- 是 Linux 使用者，聽說過 NixOS 但不知道從哪裡入手
- 曾經嘗試 NixOS，但在 configuration.nix 前感到茫然
- 想要一個「可重現、可回滾、可追蹤」的系統環境
- 對 Infrastructure as Code 有興趣，想從桌面環境開始實踐
- 管理多台機器，希望配置能統一管理

**你不需要：**

- 深厚的 Linux 系統管理經驗（但基本操作要會）
- 函數式程式設計背景（Nix 語言會從頭帶）
- 事先安裝好 NixOS（前幾章可以在 VM 中進行）
